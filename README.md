# Bulk File Renamer

A lightweight Python utility for bulk renaming files inside subdirectories.

Files are renamed using their parent directory's name as a prefix followed by a numbered sequence.

The utility supports configurable sorting, decimal or hexadecimal numbering, automatic zero-padding, filename casing, custom separators, logging, undo, and redo.

## Requirements

- Python 3.10 or newer

## Usage

Open `main.py` and configure the settings at the top:

```python
root_directory = '/path/to/root/directory'

action = 'rename'  # 'rename', 'undo', or 'redo'
log_file_path = '/path/to/rename-log.json'

renamer = FileRenamer(
    root_directory=root_directory,
    order='date-dsc',
    number_format='decimal',
    separator='-',
    case='lower',
    log=True
)
```

Then run:

```bash
python main.py
```

### Rename Files

Set:

```python
action = 'rename'
```

Configure the rename options as needed, then run the program.

### Undo a Rename

Set:

```python
action = 'undo'
log_file_path = '/path/to/rename-log.json'
```

Use the log generated by the rename you want to undo.

### Redo a Rename

Set:

```python
action = 'redo'
log_file_path = '/path/to/rename-log.json'
```

Use the same log file that was used for the undo.

> [!IMPORTANT]
> Undo and redo depend on the rename log created during the original rename operation. Keep the log file if you may need to restore or reapply filenames later.

## Directory Structure

The root directory should contain the subdirectories whose files you want to rename.

Example:

```text
root-directory/
├── folder-one/
│   ├── image-a.jpg
│   ├── image-b.jpg
│   └── image-c.jpg
│
└── folder-two/
    ├── image-a.png
    ├── image-b.png
    └── image-c.png
```

The root directory and its subdirectories are not renamed.

Only files directly inside each immediate subdirectory are processed.

For example:

```text
folder-one/
├── folder-one-1.jpg
├── folder-one-2.jpg
└── folder-one-3.jpg
```

## Actions

The `action` option determines what operation the program performs.

| Option | Action |
| --- | --- |
| `'rename'` | Rename files using the configured options |
| `'undo'` | Restore original filenames using a rename log |
| `'redo'` | Reapply renamed filenames using a rename log |

Example:

```python
action = 'rename'
```

For `undo` or `redo`, set the path to the corresponding log file:

```python
log_file_path = '/path/to/rename-log.json'
```

## Sort Order

The `order` option determines how files are sorted before sequence numbers are assigned.

| Option | Order |
| --- | --- |
| `date-asc` | Oldest modified → newest modified |
| `date-dsc` | Newest modified → oldest modified |
| `name-asc` | Filename A → Z |
| `name-dsc` | Filename Z → A |
| `size-asc` | Smallest → largest |
| `size-dsc` | Largest → smallest |
| `extension` | Group by file extension |

Example:

```python
order='date-dsc'
```

When using `date-dsc`, the most recently modified file receives the first sequence number.

## Number Format

The `number_format` option determines how sequence numbers are generated.

| Option | Format |
| --- | --- |
| `dec` / `decimal` | Decimal numbering starting at `1` |
| `hex` / `hexadecimal` | Hexadecimal numbering starting at `0` |

Example:

```python
number_format='decimal'
```

## Separator

The `separator` option determines what string is used between words and the sequence number.

| Option | Format |
| --- | --- |
| `'-'` | Hyphen-separated filenames |
| `'_'` | Underscore-separated filenames |
| `'.'` | Period-separated filenames |
| `''` | No separator |
| Any other string | Uses the provided string as the separator |

Examples:

```text
separator='-'   → example-folder-001.jpg
separator='_'   → example_folder_001.jpg
separator='.'   → example.folder.001.jpg
separator=''    → examplefolder001.jpg
separator='--'  → example--folder--001.jpg
```

> [!TIP]
> Any string can be used as the separator, but separators without spaces are recommended for cleaner and more portable filenames.

## Case Formatting

The `case` option determines how the parent directory name is formatted before being used as the filename prefix.

| Option | Format |
| --- | --- |
| `'keep'` / `'none'` | Preserve the original capitalization |
| `'lower'` | Lowercase |
| `'upper'` | Uppercase |
| `'title'` | Title Case |
| `'camel'` / `'camelcase'` | camelCase |
| `'pascal'` / `'uppercamel'` / `'uppercamelcase'` | PascalCase |

Given the directory name:

```text
Example Folder Name
```

Examples:

```text
case='keep'    → Example-Folder-Name
case='lower'   → example-folder-name
case='upper'   → EXAMPLE-FOLDER-NAME
case='title'   → Example-Folder-Name
case='camel'   → exampleFolderName
case='pascal'  → ExampleFolderName
```

Camel case and Pascal case do not use separators between words in the prefix.

## Logging

Logging is enabled by default:

```python
log=True
```

After a successful rename, a timestamped JSON file is created inside the root directory.

Example:

```text
rename-log-YYYYMMDD-HHMMSS.json
```

Each rename operation records:

- Original filename
- New filename
- Original absolute path
- New absolute path

Example:

```json
{
    "old_name": "image-a.jpg",
    "new_name": "folder-one-001.jpg",
    "old_path": "/path/to/root/directory/folder-one/image-a.jpg",
    "new_path": "/path/to/root/directory/folder-one/folder-one-001.jpg"
}
```

The log can later be used by both `undo()` and `redo()`.

> [!WARNING]
> Rename logs store absolute file paths. Moving or renaming the files or their directories after a rename may prevent that log from being used successfully for undo or redo.

Logging can be disabled with:

```python
log=False
```

## Filename Collision Handling

Files are first renamed to temporary UUID-based filenames before their final names are applied.

This prevents files within the same rename operation from colliding with one another.

Undo and redo use the same temporary rename strategy.

> [!NOTE]
> If a destination filename is already occupied by an unrelated file, the program raises an error instead of overwriting it.

## Example

Given:

```text
example-folder/
├── image-a.jpg
├── image-b.jpg
├── image-c.jpg
└── image-d.jpg
```

With:

```python
renamer = FileRenamer(
    root_directory='/path/to/root/directory',
    order='date-dsc',
    number_format='hex',
    separator='-',
    case='camel',
    log=True
)
```

The resulting filenames may look like:

```text
example-folder/
├── exampleFolder-0.jpg
├── exampleFolder-1.jpg
├── exampleFolder-2.jpg
└── exampleFolder-3.jpg
```

The exact file-to-number assignment depends on the selected sort order.

## Important

> [!CAUTION]
> This utility directly renames files on the filesystem. Test it on copied files before using it on important data. Keep generated rename logs if you may need to undo or redo an operation later.
